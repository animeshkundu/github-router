# stand_in / decide decision log

Autonomous decisions made via `mcp__decide__stand_in` (three-lab consensus: gpt-5.5 + opus + gemini) while the user was away, for the injection-surface implementation. The user reviews these on their own time. Each entry records the question, all options presented, the verdict, and what was done. Newest first.

Scope rule in effect: trivial decisions resolved here without waiting; only genuinely-important AND irreversible decisions are escalated to the user (e.g. push / open-PR / merge remain held for the user).
